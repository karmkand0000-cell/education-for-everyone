# Education For Everyone (सबके लिए शिक्षा)

Free learning portal for India: every subject from Class 6 to PhD in simple language, with free video classes and guides for every major competitive exam.

**Live:** https://karmkand0000-cell.github.io/education-for-everyone/

- Every NCERT chapter for Classes 6-12 (964 chapters) in Hindi and English, each with an animated, interactive visual
- 21 subjects up to Graduation, PG and PhD (1,450 chapters and lessons in total): Maths, Science, Physics, Chemistry, Biology, Computer Science, IT, AI Skills, History, Geography, Polity, Economics, Hindi, English, Sanskrit, Accountancy, Commerce, Finance, Education, Music, Dance
- Each lesson: simple notes, a solved example, free YouTube video classes (Hindi or English), progress tracking
- Complete study notes (1,439 topics, solved examples, study plans) for 32 competitive exams: UPSC, State PSC, SSC, banking, railways, defence, JEE, NEET, CUET, GATE, NET, CTET, CAT, CLAT, CA and more
- Search across everything; links to NCERT, DIKSHA, SWAYAM, NPTEL and other free official libraries

The whole site is one file, `index.html`. Content is edited in the Admin panel of the Claude version of the portal; upload the updated file here to refresh this site.
